# Changelog

## Current documentation status

This documentation copy tracks the source-audited networkmodel documentation state. The current documented optimizer is `jaxopt.ProjectedGradient` with `projection=project_bounds`, and the current ODE solver family is `diffrax.Kvaerno4` or `diffrax.Kvaerno5` through `DiffraxSolverConfig`.

## What this module does not do

This page does not list historical features that are absent from the current networkmodel source inventory. It does not describe unsupported optimizer choices.
